# sphereswitch (CLI)

Un solo comando: copia la plantilla de `sphereswitch.config` a tu proyecto.

```
npx sphereswitch init
```

Pregunta una cosa (TypeScript o JavaScript), escribe `sphereswitch.config.ts`
(o `.js`) en el directorio actual y muestra los siguientes pasos. Si el archivo
ya existe, pide confirmación antes de reemplazarlo.

No detecta el proyecto, no instala dependencias y no configura el Provider por
ti — eso lo haces tú, a propósito.
